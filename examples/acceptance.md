# Acceptance example — empty material library

## Input

> The empty state and upload entry for a new material library have been implemented. Prepare an acceptance summary.

## Expected response characteristics

The response should describe the visible empty state and upload entry, then explain that a first-time user understands why the library is empty and what to do next.

Its review path should include opening a new account's library, checking the empty state, uploading a file, and confirming the list replaces the empty state without a refresh. It should separate that verified path from unverified large-library, upload-failure, and narrow-screen behavior.

Its next recommendation should identify the most valuable follow-up, such as validating upload failure copy, and mark that work as outside the delivered scope.
